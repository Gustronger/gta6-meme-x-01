A GTA 6 meme about the thirteen-year wait, posted on X to promote make.fun — entry for the [gta6-meme-x-01 bounty](https://make.fun/bounty/gta6-meme-x-01) on make.fun.

The post itself is the entry: its first picture is the meme and its text carries make.fun and the entrant's play code. `main.ts` copies `POST.json` (the post's address on X) to `/output/POST.json`, where the gate reads it.
